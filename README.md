## 🎯 Suggested reading path for quantitative interviews

1. **Math:** Linear Algebra → Discrete Mathematics → Mathematics for Machine Learning.
2. **Probability:** Introduction to Probability → OpenIntro Statistics.
3. **Programming:** Think Python → Learn C++ → Open Data Structures.
4. **Algorithms:** Competitive Programmer's Handbook → Erickson's Algorithms.
5. **Quant:** Forecasting → Portfolio Optimization → Open Quant Live Book.
6. **ML:** Introduction to Statistical Learning → Dive into Deep Learning.
