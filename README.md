## ➕ Add a book

1. Upload a PDF to its subject directory under `books/` (create the directory if needed).
2. In the relevant table above, replace the placeholder with the book title, author, and its real relative file path.
3. Example for a file named `my-book.pdf` stored in `books/python/`:

```markdown
| My Book | Author Name | [📖 Open PDF](books/python/my-book.pdf) |
```

**Note:** GitHub can display many PDF files directly in the browser. For copyrighted books, upload only files you have permission to distribute; otherwise link to legal publisher or open-access copies. For files exceeding GitHub's normal file size limits, use an external legal hosting link.
